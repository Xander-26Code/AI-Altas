# 选择学习路线

每条路线都只选择当前目标所需的内容。专题编号用于检索，**不代表必须按 01 到 27 全部读完**。先完成先修自测，再用阶段成果判断是否继续。

路线表中的“主资源与范围”给出一套默认材料；专题页列出替代课程、补充阅读和更细的练习。先选定一套主线，再按阶段推进，不把同主题的所有课程都加入计划。

## 投入怎样估算

以下是为规划日程准备的宽范围，包含阅读、推导、练习、调试、复盘和项目；不是测量得出的完成时长，也不是就业保证。按每周 8–12 小时的持续有效学习折算月份，遇到补基础、外文阅读、硬件等待，应额外留出时间。已有基础按自测跳过，不靠压缩练习时间加速。

专题页的时间以系统学习一份主教材和完成一个项目为范围。路线会选读专题，并共享基础与实验，**不能把所有专题时长简单相加，也不能把路线总时长理解为读完所有推荐课程**。精通一个方向还需要长期项目与研究经验。

| 路线 | 适合谁 | 规划投入 | 约需日历时间 | 阶段成果 |
|---|---|---|---|---|
| [零基础](beginner.md) | 编程与数学都需补起 | 600–1,000 小时 | 12–30 个月 | 一份独立的 ML 项目报告 |
| [算法工程](algorithm.md) | 已会 Python 和基础数学 | 450–750 小时 | 9–22 个月 | 有基线、消融与部署的模型项目 |
| [应用开发](application.md) | 已具备软件开发能力 | 300–500 小时 | 6–15 个月 | 有引用、评估和失败处理的应用 |
| [LLM 训练](llm.md) | 已完成深度学习基础 | 450–800 小时 | 9–24 个月 | 小模型训练/微调与评估记录 |
| [AI Infra](infra.md) | 已有编程、训练循环和系统基础 | 500–900 小时 | 10–27 个月 | 可复现的训练或推理优化报告 |
| [研究入门](research.md) | 已有一个方向的课程基础 | 350–650 小时 | 7–19 个月 | 一份含失败分析的论文复现 |

跨度大的原因是每周投入、已有经验与项目难度不同。这里的月份使用约 4.3 周/月的粗略换算并向外取整；无需以“赶上进度表”为目标。

## 三个共用检查点

1. **能解释**：不看笔记说明一个核心机制及其适用条件。
2. **能实现**：独立改动或实现一个关键部分，而不是只运行别人代码。
3. **能验证**：使用基线、固定评估集、错误案例和可复现环境判断改动是否有效。

只有时间不足时，先缩小项目和选修范围；不要省略数据切分、测试与误差分析。[开始之前](../start.md) 提供自测，[学习方法](../guides/study-method.md) 提供记录模板。
