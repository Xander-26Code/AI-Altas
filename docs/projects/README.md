# 实验与项目任务书

前四项包含仓库内可运行代码，使用 Python 3.9+ 标准库、CPU 和原创小数据，不调用外部模型。后四项是进阶任务书，需要你自行实现、选择模型和准备环境；本仓库没有声称已完成这些训练或服务实验。

| 项目 | 当前交付 | 训练的能力 | 条件 |

| [01 线性回归](01-regression.md) | 可运行代码与测试 | 损失、梯度、泛化 | CPU |
| [02 检索与评估](02-retrieval.md) | 可运行代码与测试 | TF-IDF、证据、Recall / MRR | CPU |
| [03 因果 attention](03-attention.md) | 可运行代码与测试 | 矩阵形状、softmax、mask | CPU |

## 统一交付标准

至少保存：问题定义、数据来源与切分、环境和随机种子、基线、指标定义、实验结果、失败样例和复现命令。能运行示例是开始；能解释、修改并独立验证，才是这一项练习的成果。

不要将这些玩具样例的分数作为真实模型或真实业务的能力指标。项目耗时因先修和改动幅度而异，纳入所选学习路线的阶段预算，不另做“几小时掌握”的承诺。
