# 项目 07 · 有边界、可恢复的 Agent

这是项目任务书。先修：[应用开发](../topics/11-ai-applications.md)、[Agent](../topics/13-agents.md)。先使用模拟工具和虚构数据，再根据需要接入模型。

## 场景

实现一个只处理个人测试目录的文档整理助手：读取文件清单、建议标签、生成待处理列表。写入或删除采用独立动作边界和确认流程，不能由检索内容自行获得权限。

## 实施与验收

1. 用状态机表达开始、检索、提议、等待确认、执行和结束，设最大步数与预算。
2. 为工具声明 schema、允许的目录与动作；将输出当作不可信数据验证。
3. 用固定场景测试成功、超时、非法参数、重复调用、中途恢复和恶意文档指令。
4. 保存事件记录，使用幂等策略，保证重试不会重复改变状态。
5. 和固定工作流比较成功率、调用数、成本和人工接管次数，判断是否真的需要动态规划。

交付应包括可重放轨迹、工具拒绝的案例、成功与失败统计。不要用一次演示推断自治能力，也不要把模拟接口测试称作真实模型评测。
