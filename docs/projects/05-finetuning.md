# 项目 05 · 微调是否真的改善了目标任务

这是项目任务书，仓库未附训练结果。先修：[LLM](../topics/09-llm.md)、[微调对齐](../topics/14-finetuning-alignment.md)。实际训练一般需要兼容 GPU；在选模型前先做容量估算。

## 实施顺序

1. 选一个清晰任务，例如固定 schema 的信息抽取，写出失败类型和验收指标。
2. 准备有权限使用的数据，先去重、按来源或实体切分训练/验证/测试。
3. 测未微调底座，保留提示与少样本基线。
4. 固定模型 revision、训练配置、样本顺序与随机种子，做一组 SFT/LoRA。
5. 在验证集选配置，锁定后运行测试；额外评估不属于训练任务的能力是否退化。

## 交付

提交数据说明、底座许可、训练脚本/配置、基线与微调结果、格式有效率、任务正确率、显存、耗时、失败样例及回滚方法。记录样本量与不确定性，不凭几个好看的例子宣布胜出。

如果提升来自数据清洗或提示变化，要单独对照；损失下降不能替代任务评估。可进一步比较 RAG 与微调，但必须保持测试问题和资源预算可解释。
