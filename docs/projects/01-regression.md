# 项目 01 · 手写线性回归

目标：从一个可推导、可检查的模型理解训练。先修：[Python](../topics/02-programming.md)、[数学](../topics/01-math.md)。源码位于仓库 `examples/linear_regression.py`。

## 运行

```bash
python3 examples/linear_regression.py
```

数据由 `y=3x+2+噪声` 合成。训练集和测试集使用不同的固定随机种子；参数只能用训练集拟合。程序输出初始训练误差、最终训练/测试误差、权重和偏置。参数应接近 3 和 2，允许噪声导致偏差。

## 实验

1. 推导均方误差对 w、b 的偏导，与代码逐项对应。
2. 改变学习率，观察收敛速度与发散；不要只看最后一个数。
3. 缩小训练集、增加噪声，比较训练和测试误差。
4. 增加一个非线性项，解释线性模型的误差为何无法仅靠多训练消除。

## 验收

用中心差分验证解析梯度；提交两组学习率对照和一个失配案例。测试集仅用于最终检查，选择学习率时应另外划分验证集。仓库测试验证了梯度、信号恢复和未见合成数据误差，不代表任何真实业务性能。
