# 项目 08 · 一份可信的论文复现

这是项目任务书。先选一个数据可得、算力可控的实验；从 [研究路线](../roadmaps/research.md) 确定先修。

## 开始前写清楚

- 复现哪张表、哪项结论；是否有合法可用的数据与作者实现。
- 原论文与本次设置的模型、数据、指标、算力、训练预算差别。
- 成功判据、允许偏差、停止条件和失败时要保留的记录。

## 实验顺序

先跑基线并验证评测实现，再复现方法；固定环境和随机种子，按任务需要运行多个种子。一次只改一个关键因素，保留全部计划内运行，包括负结果。不能用更大模型、更长训练或不同切分制造不可比提升。

## 报告模板

```text
研究问题：
来源与版本：
原始结论和适用条件：
数据、许可与切分：
环境与复现命令：
基线和实验预算：
结果、不确定性与失败案例：
与原论文设置的差异：
受到支持的结论 / 仍未解决的问题：
```

复现不一致时先排查数据、随机性、实现和评测口径，再讨论方法问题。缩小规模后的实验只能支持对应范围内的结论。写明未运行的部分，避免把读论文笔记当作实验结果。
