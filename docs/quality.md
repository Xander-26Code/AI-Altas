# 质量记录与检查边界

本轮修订日期：2026-10-01。校验覆盖 Markdown 文件、SVG/图片路径、文件名大小写、本地标题锚点、资源元数据和生成站点的 HTML 跳转。外部地址逐一发起有限大小的 GET 请求，记录 HTTP 状态与最终重定向地址。

## 如何复查

```bash
python3 scripts/check_content.py
python3 scripts/build_catalog.py --check
python3 -m unittest discover -s tests -v
python -m mkdocs build --strict
python3 scripts/check_site_links.py
python3 scripts/check_external_links.py
```

每个外部 URL 的状态、来源文件、时间和重定向记录保存在仓库 `data/link-check.json`。外部检查不把 403、429、TLS 错误或超时自动算作通过；这些可能由机器人限制或当前网络造成，需要补充人工核实。

## 本轮修正

- 补齐 README 引用的 SVG、知识地图、路线页、资源目录、项目页及维护文档。

- 区分已有可运行代码与进阶项目任务书，避免把规划中的实验表述为已完成。
- 增加源文件和生成站点两层链接检查，并加入提交检查流程。
- 修正资源筛选页的侧边目录，避免导航指向已被交互筛选隐藏的静态表格；GitHub 中仍保留完整表格。

## 验证不能证明什么

网页能返回并不证明全部内容正确、永久免费或免登录；课程视频、作业、外部锚点和动态加载内容需要分别检查。外链状态是检查时的快照，不保证未来可用。GitHub 上的文件只有在本地修改提交并推送后才会更新。

资源内容核实范围见 [调研记录](research/README.md)，可运行示例范围见 [项目目录](projects/README.md)。代码测试验证的是教学例子的数值与行为，不是外部模型的质量或速度。
