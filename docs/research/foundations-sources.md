# 基础与算法：来源核实记录

内容核实日期：2026-09-30；链接与措辞复查：2026-10-01。对应 01–08 八个专题，50 个不同资源地址。逐条的核实说明保存在 `data/resources-foundations.json` 的 `evidence` 字段。

核实范围是大学、教材作者、项目官方页面或作者维护教程的正文和目录，不表示已经完成全部课程或运行每个外部实验。机器请求和浏览器复核的差异见 [质量记录](../quality.md)。

## 主线选择

D2L 将理论解释和代码交替组织，适合边推导边实现；mlcourse.ai 提供机器学习主题与实践，进阶作业的收费边界单独标注；大学课程提供理论与作业骨架，官方库文档用于核对实现。新手先选择一份主教材，其他资源按问题补充。

## 已确认的使用限制

- mlcourse.ai 的进阶作业并非全部免费，不能将所有课程权益笼统标为免费。
- CS224N、CS231n 的当年视频可能限校内；应区分公开讲义、往年公开视频与校内资源。
- Szeliski 教材电子版需按作者页面说明获取，不能承诺没有步骤的直接下载。
- Deep Learning 作者网站提供在线 HTML，本仓库不链接未经授权的教材镜像。

学习时长采用主教材、练习与项目的宽范围预算。完成一页导读和完成一门课程的工作量不同，不能按阅读本文的时间估算领域学习时间。
