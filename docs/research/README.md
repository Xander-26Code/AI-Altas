首版调研日期：2026-09-30。这里记录真实参考过的路线、我们借鉴的信息组织方式，以及资源核实边界。它不是对这些项目教学效果的量化排名，也不使用 Star 数替代质量判断。

## 资源如何进入正文

1. 先明确读者需要完成的任务，再选一份主教材与少量补充资料。
2. 优先大学课程主页、书籍作者主页、项目官方文档、原论文及作者实现。
3. 直接打开页面核实标题和主题。打开受限但有可靠索引证据的条目，明确标为 `search-verified`；不会标成已读全文。
4. 元数据记录语言、难度、费用、实验算力、推荐理由与核实日期。读资料免费不代表云算力免费。
5. 课程示例没有全部重跑。本站实际运行过的代码只限于 [本仓库的入门实验](../projects/README.md)。

## 这是有边界的第一版

AI 不存在一张永久完备的目录。本版建立 27 个学习入口：基础与算法、模型与应用、系统与部署、交叉领域。每个入口提供学习骨架与精选资料；读完导读不等于完成相应大学课程。尚未展开成独立章节的领域在 [覆盖范围](../map.md) 中明确列出。

资料核实是一次有日期的快照，不是自动保证未来可访问。HTTP 200 只表示服务器返回了页面，不能证明内容正确、免费或适合某个学生。资源的可读性检查、元数据检查和实际实验验证分别记录。

## 原创与署名

本仓库自行筛选资源、编排学习顺序、设计实验，不搬运他人的课程正文、图表、视频或电子书。外链保留原作者与项目身份。暂不收录盗版教材、未经授权的网盘合集、无说明的镜像或联盟营销链接。

如果参考资料和本仓库解释不一致，请优先核对原文适用条件，并按 [贡献指南](../contributing.md) 提交具体勘误。
