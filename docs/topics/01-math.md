# 01 · 数学基础

> 目标：读懂常见模型的公式、检查维度、解释优化过程，并能用小实验验证结论。先修：高中代数与函数；代码练习可和 [编程基础](02-programming.md) 并行。预计主动学习 **45–75 小时**，包括推导和练习；这是入门达标估算，并非修完所有课程的时间。纸笔与普通 CPU 即可。

数学学习最容易走向两个极端：完全跳过公式，或要求自己先学完整套大学数学。更有效的切入点是一个具体模型：每遇到一个符号，能说清它表示什么、维度是多少、改变它会发生什么。先掌握支撑线性回归和神经网络训练的最小闭环，再按研究问题补课。

## 学习顺序

1. **向量与矩阵（10–15 小时）**：内积、矩阵乘法、范数、线性变换、秩；画出二维变换前后的点。
2. **导数与梯度（10–15 小时）**：变化率、偏导、链式法则、方向导数；从标量过渡到向量。
3. **概率与统计（12–20 小时）**：条件概率、期望、方差、常见分布、似然、采样误差；每个概念配一个模拟。
4. **优化与数值（8–15 小时）**：梯度下降、学习率、凸性、病态问题、浮点误差。
5. **把知识串起来（5–10 小时）**：推导并实现最小二乘，比较解析法与迭代法。

做应用开发时，可先把前三项学到能阅读和使用的程度。做算法研究时，再系统补特征分解、奇异值分解、概率图模型、统计推断和优化理论。学习顺序不等于一次性学完才可以实践。

## 核心概念：梯度为什么能指导学习

假设用房屋面积和房龄预测价格，特征矩阵 \(X\in\mathbb{R}^{n\times d}\) 每行对应一个样本，参数 \(w\in\mathbb{R}^{d}\)，预测为 \(Xw\)。可加一列全为 1 的特征，把截距并入参数。均方损失写成：

$$
L(w)=\frac{1}{2n}\|Xw-y\|_2^2,\qquad
\nabla_w L=\frac{1}{n}X^\top(Xw-y)
$$

梯度的每一维回答：“只把这个参数增加一点点，损失会怎样变化？”它是局部变化率，不是模型犯错的数量。更新 \(w\leftarrow w-\eta\nabla L\) 是沿局部下降方向迈一步；步长 \(\eta\) 过大，可能跨过低点反而损失升高。

用只有一个参数的例子看得更清楚：\(L(w)=\frac12(2w-6)^2\)。在 \(w=0\) 时，梯度为 \(-12\)；若学习率为 0.1，新参数为 1.2，预测从 0 变为 2.4，损失由 18 降到 6.48。若学习率为 1，新参数成为 12，预测为 24，损失升到 162。负梯度给方向，学习率决定局部近似还能否成立。

现在检查矩阵维度：残差 \(Xw-y\) 长度为 \(n\)，左乘 \(X^\top\) 后长度为 \(d\)，正好与参数相同。这种“形状审计”能提前发现大量实现错误。若面积用平方米、房龄用年，而另一个特征数值大几千倍，损失曲面的不同方向可能弯曲程度悬殊，固定步长会很难选。标准化有时改善优化条件，但均值和标准差必须只从训练数据估计；它不保证所有问题都因此更好。

另一条重要联系是概率：最小化平方误差可由“给定输入后，目标等于模型预测加独立同方差高斯噪声”的最大似然估计导出。这个结论带有假设；换成重尾噪声、计数或分类目标，合适的损失也可能改变。可以对照 [MML](https://mml-book.github.io/) 的线性回归部分继续推导。

## 核心知识表

| 知识 | 必须能回答 | 在 AI 中的用途 |
|---|---|---|
| 内积、范数、余弦 | 相似与距离为何不是一回事？ | 检索、嵌入、正则化 |
| 矩阵乘法与秩 | 哪些信息能被线性变换保留？ | 线性层、降维、低秩近似 |
| 导数、链式法则 | 参数通过多条路径影响输出时如何求导？ | 反向传播 |
| 期望、方差、条件概率 | 已知信息改变后概率如何更新？ | 不确定性、贝叶斯方法 |
| 似然与交叉熵 | 模型对观察数据赋了多少概率？ | 分类与语言模型训练 |
| 特征值、SVD | 哪些方向包含主要变化？ | PCA、压缩、数值稳定性 |
| 梯度下降与凸性 | 何时能谈全局最优？ | 优化、收敛分析 |

## 精选资源

先选一条主线：中文快入门选 D2L；想系统补数学选 MML，卡住的部分再查 MIT 或 Stat 110。**不需要同时修完六份材料。**“免费”指推荐的公开内容；纸书、证书或云算力可能另收费。

- **[Mathematics for Machine Learning](https://mml-book.github.io/)**｜英文 · 进阶 · 免费 · CPU。以机器学习问题连接数学；先读第 2–7 章，再做线性回归与 PCA notebook。
- **[MIT 18.06 Linear Algebra](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)**｜英文 · 入门 · 免费 · 无。建立矩阵几何直觉；选线性方程组、子空间、正交投影和特征值，配习题。
- **[MIT 18.01SC Single Variable Calculus](https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/)**｜英文 · 入门 · 免费 · 无。补导数与优化；先读 Differentiation 和 Applications，积分按需补。
- **[Harvard Stat 110](https://stat110.hsites.harvard.edu/)**｜英文 · 入门 · 免费 · 无。练概率推理；优先条件概率、随机变量、期望和常见分布。
- **[Convex Optimization](https://web.stanford.edu/~boyd/cvxbook/)**｜英文 · 研究 · 免费 · CPU。作为深入优化的参考；读凸集、凸函数和无约束优化，暂缓对偶细节。
- **[动手学深度学习：预备知识](https://zh.d2l.ai/chapter_preliminaries/index.html)**｜中文 · 入门 · 免费 · CPU。用张量代码复核数学；选 2.3–2.6 的线性代数、微积分、自动微分和概率。

## 实践任务与验收

**任务 A：二维线性回归实验。** 自己生成 200 个样本，保留真实参数；分别用梯度下降和数值最小二乘求解器拟合。不要显式计算矩阵逆来作为默认数值实现。

- [ ] 写清 \(X\)、\(w\)、\(y\)、残差和梯度的形状。
- [ ] 用中心差分检查一个参数梯度；双精度、合适步长下与解析梯度接近，并解释误差来自哪里。
- [ ] 比较三种学习率，画出损失曲线；能解释发散或收敛变慢。
- [ ] 将一个特征放大 1000 倍，再标准化，记录训练变化。

**任务 B：概率模拟。** 模拟硬币或骰子，比较 20、200、2000 次样本的均值波动；用重复实验区分“单次估计很接近”与“方法总体稳定”。验收是写出一段自己的解释，而不是只交图。

## 常见误区

- **会背公式等于理解。** 至少给每个公式一个小数值例子和一条适用假设。
- **相关意味着因果。** 条件预测不自动回答干预后会发生什么。
- **凸优化教材能解释所有神经网络训练。** 神经网络通常非凸，不能照搬全局最优保证。
- **浮点计算就是实数计算。** 极小步长、极大指数和显式求逆都可能引入数值问题。
