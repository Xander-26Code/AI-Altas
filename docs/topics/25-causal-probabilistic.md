# 25 · 概率建模与因果推断

> 目标：表达不确定性，区分预测、干预与反事实问题。先修：[概率统计](01-math.md)、[机器学习](04-machine-learning.md)。具备先修后，系统学习主教材、做练习并完成一个项目，建议预留 **140–260 小时**。补先修另计；入门实验用 CPU。

## 两个经常被混淆的问题

“哪些用户更可能流失？”是预测问题。“给这些用户发优惠券会不会减少流失？”是干预问题。即使预测非常准，第二个问题仍可能答错，因为历史上被发券的用户通常并非随机选中。

概率建模也不自动带来因果结论。贝叶斯模型可以把参数不确定性和观测噪声纳入推断，但如果因果结构或可识别假设不成立，后验分布再精细也无法补回缺失的识别条件。

## 学习顺序

1. 概率分布、条件独立、似然、先验与后验；比较 MLE 和 MAP。
2. 贝叶斯网络、马尔可夫随机场、精确推断、MCMC 与变分推断。
3. 后验预测检查、校准、模型失配与不确定性来源。
4. 潜在结果、结构因果模型、DAG、混杂、碰撞点与选择偏差。
5. 随机实验、后门调整、匹配、加权、双重稳健估计与敏感性分析。
6. 异质处理效应、策略学习、工具变量和时间变化处理；按真实问题选修。

## 核心概念：相关性和干预差在哪里

设 `X` 表示发券，`Y` 表示购买，`Z` 表示历史活跃度。若运营更常给活跃用户发券，而活跃用户本就更可能购买，则观测到的 `P(Y|X)` 同时混入了 `Z` 的影响。

如果 `Z` 足以阻断 X 与 Y 之间的后门路径，并满足一致性、可交换性和正值性等条件，可用调整公式：

```text
P(Y | do(X=x)) = Σ_z P(Y | X=x, Z=z) P(Z=z)
```

直觉上，是把不同活跃度组的效果按同一总体构成重新加权，避免比较人群组成完全不同的两组。不要把这个公式视为任何表格都能直接套用的操作：未测量混杂、缺乏重叠或错误调整碰撞点，都会破坏结论。建议以作者公开教材的因果假设章节为主线。[Causal Inference: What If](https://miguelhernan.org/whatifbook)

## 实践：在已知真相的数据中识别偏差

自行生成 2,000 条合成记录。让历史活跃度 Z 同时影响是否收到处理 X 和结果 Y，并把真实处理效应固定为 2。比较简单均值差、控制 Z 的回归与一种加权估计。再增加一个没有放进模型的混杂变量，观察估计偏差。

验收包括：数据生成方程、随机种子、因果图、目标量、估计结果与不确定性区间；明确写出哪些假设由模拟器保证、哪些在真实数据里无法直接证明。至少展示一个“置信区间很窄但估计错了”的设定。

概率建模扩展：给小样本二项数据设两个不同先验，比较后验预测。说明小数据时先验影响为何更大，观测增加后如何变化。不要只报告一个均值而隐藏整个分布。

## 易踩的坑

- 随意控制更多变量可能引入选择偏差，变量越多不是越安全。
- SHAP 等归因解释不自动等价于干预效果。
- 因果发现算法输出的图依赖假设与数据质量，不能替代领域判断。
- 高预测准确率、统计显著和实际可行动的效果，是三件不同的事。
