# 环境、算力与学习成本

本仓库四个基础实验只需要 Python 3.9+ 标准库。文档站建议 Python 3.11+；具体依赖锁定在仓库根目录的 `requirements-docs.txt`。不需要 API Key 或模型下载就能开始学习。

## 先按任务选择环境

| 活动 | 起步条件 | 注意点 |
|---|---|---|
| 阅读、数学、回归、基础检索 | 普通 CPU | 先缩小数据，验证思路 |
| 小型经典 ML、图算法、时序 | CPU 通常可行 | 数据和算法复杂度仍会影响内存 |
| 深度学习小实验 | CPU 可验证，GPU 可加速 | 不同设备结果与速度可能不同 |
| 模型微调、图像生成 | 依模型而定，常需 GPU | 先核对权重、激活、优化器、上下文 |
| CUDA/Triton、真实服务压测 | 兼容加速器及驱动 | Apple GPU 不能直接当作 CUDA GPU |
| 多卡训练 | 多设备与相应通信环境 | 单机模拟只能检验部分行为 |

不在本指南固定推荐某个显卡价格或云套餐。选型前检查官方支持、模型配置和预算，做小规模试跑；阅读免费不代表平台资源永久免费。

## 保留可复现环境

每个外部课程或实验独立建虚拟环境，按其官方说明安装匹配的版本，记录 Python、框架、驱动、加速器和模型 revision。不要把所有教程的依赖混装到系统 Python。仓库的文档依赖只负责构建 Wiki，不包含训练框架。

遇到错误时先记录完整错误信息、复现命令、最小输入与环境版本。缩小到 CPU 或单进程基线，确认正确性后再恢复复杂配置。

## 预算应包含什么

模型权重、数据和缓存占用存储；训练、推理、空闲实例及网络可能分别计费。按任务预设运行上限和停止条件，记录失败重试的成本。没有 GPU 时可先完成数据、评估与 CPU 验证，但要在报告中区分未执行的训练部分。
