## 每个专题，回答五件事

**需要什么基础 → 有哪些资源 → 选哪条主线 → 按什么顺序读和练 → 做到什么算完成。**

你不必先读完所有基础才能尝试应用，也不必因为某个方向热门就放弃原来的专长。路线是可调整的学习建议；用阶段成果决定继续深入还是补课。

本版建立主干和交叉领域入口，不声称覆盖 AI 的全部知识。外部资料有明确来源和核实日期，仓库实验与外部课程的验证范围分开记录。完整边界见 [知识地图](map.md) 与 [质量记录](quality.md)。
